# Public Procurement and Government Spending in Nigeria – Excel Analysis

## Project Overview
This project focuses on analysing public procurement and government spending in Nigeria using Microsoft Excel.

## Project Objectives
- Organise and clean procurement and government spending data.
- Examine spending patterns and expenditure trends.
- Identify useful insights from the available data.
- Support transparency, accountability and informed decision-making.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel formulas
- Data cleaning and visualisation

## Project Process
1. Imported and reviewed the available dataset.
2. Cleaned and organised the data.
3. Analysed spending information using Excel.
4. Created visualisations to communicate findings.

## Key Findings
1. Delayed and Abandoned Projects. 140 of 514 Contracts(27%) are delayed and Abandoned
2. Spending Pattern works and housing, water Resources and Power are the three largest sectors, together over a third of the #99.1bn contract Value
3. Procurement and contractor risk 44% of value was awarded by open competitive bidding yet 18% went through direct or sole sourcing outside open competition. 

## Recommendations
1. Strengthen monitor of delayed and abandoned projects.
2. Improve transparency of procurement, funding and project process.
3. Monitor contractor concentration and procurement risk.
4. Use Data Dashboards for continuous management oversight.
